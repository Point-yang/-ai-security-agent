# 项目组交付说明

交付整理日期：2026-10-19；实现与工程测试基准：2026-10-18。交付对象是当前可运行实现及配套证据。

| 目录 | 用途 |
|---|---|
| `src/` | 当前服务、采集、检索、Agent、静态界面 |
| `config/`、`migrations/` | 运行配置、数据库迁移；旧命名仍有运行和测试引用 |
| `scripts/`、`tests/` | 运维、实验复核脚本和回归测试 |
| `data/` | 脱敏公开情报快照、原文和当前使用的本地模型 |
| `docs/submission/` | 当前交付、架构、使用和评测说明 |
| `docs/`中两个旧JSON | 历史契约测试的只读小型资料 |
| `evidence/` | 选定评测与失败依据，附来源文件哈希 |
| `validation/` | 本次交付验证结果 |
| `MANIFEST.json` | 提交文件逐项SHA-256；清单本身由ZIP外部校验文件绑定 |

排除 `.env`、`.venv`、`.git`、IDE设置、缓存、采集日志、历史私有会话、恢复库、旧Word/PPT/视频/ZIP、模型检查点以及递归实验副本。不会把先前的文档或实验结果重新标为当前验收。

本地原工作区中，运行主库、原文、模型、检查点及采集锁保留。已核验的历史资料压缩到 `archives/cleanup-20261016/history.tar.gz`，并从原位置移除；逐项路径及SHA-256记录在同目录 `manifest.json`。私人归档不属于提交包。需要查旧实验时，应先解压到新的隔离目录，再按清单选择性恢复，避免覆盖当前主库。旧README另存于归档目录。

包中Python依赖通过三份锁文件安装，Node仅用于前端测试。首次依赖安装需要网络；语义模型已在包内，浏览现有资料不需要云模型。实时采集需要来源网络，新Agent生成需要部署方自己的模型配置。Docker使用新PostgreSQL数据卷，不直接复用SQLite演示快照。

本次另行制作了初赛技术报告Word/PDF、技术讲解PDF和实际操作视频，并以单独初赛材料包交付。PPTX编辑源和运行工程保留给团队。赛题注明源码不单独提交，比赛材料包不包含工程源码、数据库或密钥。

本轮交互改进包括首次使用入口、三来源只读案例、可见的来源阅读跳转、显式会话与资产选择、键盘回车查询、等待反馈和评测方法分层。新增评测摘要来自原始冻结文件。

第二轮清理实际删除了确认无依赖的缓存与重复项，包括旧提交包的完整重复解压目录、未启用模型下载、旧视频后期中间物和已有保留副本的重复媒体。冻结协议引用的证据副本、当前模型哈希集合、原文、主库和恢复状态仍保留。清理与验证摘要见运行工程的validation目录。
