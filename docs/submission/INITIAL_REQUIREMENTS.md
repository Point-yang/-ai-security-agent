# 校内初赛材料清单

依据本项目留存的赛题九原始 PDF 第七部分 1.1，以及大赛报名通知。校内初赛由各校组织，具体上传入口、命名、文件大小和时间以本校通知为准。现有赛题文件没有给出视频时长或文件大小上限，不额外假定这些限制。

| 初赛要求 | 交付文件 | 内容 |
|---|---|---|
| 技术报告 Word 一份 | 知盾初赛技术报告.docx | 总体架构、Agent设计、三模块、选型、流程图、实现、代码说明、效果、测试分析和创新 |
| 同版技术报告 PDF 一份 | 知盾初赛技术报告.pdf | 与Word同版，封面/目录后含重要内容预览 |
| 操作演示视频 | 知盾初赛操作演示.mp4 | 真实页面交互帧与字幕，压缩等待空档；历史Agent回放与隔离虚构资产明确标注 |
| 技术讲解 PPT 以 PDF 提交 | 知盾初赛技术讲解.pdf | 系统方案、框架、核心功能、实验与演示路线 |

赛题原文注明“源代码由企业在参赛平台上审阅，不单独提交，避免泄露”。因此团队运行工程包、可编辑PPTX、私人历史归档和 `.env` 不放入初赛比赛材料 ZIP。上述四个正式文件构成比赛材料；文件校验清单可由团队保留。

本次材料不代替报名表、学校审核或参赛系统提交操作。学校或平台若另外规定队名、成员、导师、命名格式或大小限制，应据实填写并选择对应文件，不能凭空编造身份信息。大赛通知把初赛列为2026年10月25日前由各校组织；本清单按留存通知解释，不视作本校最新安排。
