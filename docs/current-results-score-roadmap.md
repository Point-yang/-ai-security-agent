# 当前成果、估分与冲奖路线

评估日期：2026-09-22。评分依据为赛题九初赛和决赛 100 分评分表。以下为内部保守估分，不代表评委最终成绩；只有已经实现且有测试或真实库证据的能力才计入当前分。

## 当前成果

### 情报监测

- 5 个来源适配器、4 类来源：GitHub 安全公告、vLLM 厂商公告、NVD、CISA KEV、Crossref 学术元数据。
- 6 个定时目标，周期 30 分钟至 6 小时；支持增量水位、分页续传、失败退避、HTTP 条件请求、幂等去重和原文字节留存。
- 真实库 509 个事件、46 份已保存原文；当前检索链使用其中 28 份原文。

### 情报富化

- 实体、版本范围、CVSS、CPE、资料质量标记和来源路径。
- CycloneDX 资产导入；package/CPE 三态判断 `affected/not_affected/unknown`。
- 175 个共享 CVE 字段比较，包括 agreement、variation 和 severity conflict；不自动裁决来源。
- 资产证据图和事件历史 trace，可验证 SHA-256、JSON Pointer 和字段值。
- 真实库 3370 个字段证据全部复验通过。

### 情报问答与智能体轨迹

- 持久词项索引、正式/候选集合、结构化过滤和抽取式可引用问答。
- 持久多轮会话，资产上下文只允许显式继承或切换。
- 五跳证据路径：事件选择 → 跨来源比较 → 资产 exposure → event trace → 原文证据。
- unknown、资料缺口和冲突生成独立补证任务；补证任务与真实联网采集分开。
- 显式资产规则建议、冲突人工复核、答案审计和确定性重放。

### 工程与验收

- FastAPI、SQLAlchemy、Alembic、SQLite/PostgreSQL 配置、Docker Compose 和本地只读工作台。
- 86 项自动化测试通过；ruff、迁移一致性、前端语法和 Compose 配置通过。
- 真实库 2498 个检索片段与 28 份当前原文全部通过引用复验。
- 虚构评测资产、会话与真实库隔离。
